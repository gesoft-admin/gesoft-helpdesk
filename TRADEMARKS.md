Gesoft names, logos, trademarks and brand assets are **not** licensed under the
AGPL-3.0 licence that covers this software. The licence grants rights to the
code; it does not grant permission to use anyone's marks.

This public repository contains only generic placeholder branding assets —
`public/brand/default-logo.svg` and `public/brand/default-favicon.svg`. They are
deliberately anonymous and belong to no one in particular.

Deployment-specific branding assets are supplied separately by the operator of
an instance and are not part of this source. See
`Modules/GesoftBranding/Config/config.php` for how an instance points at its
own.

If you run this software, brand it as yourself: set `HELPDESK_BRAND_NAME`,
`HELPDESK_BRAND_LOGO` and `HELPDESK_BRAND_FAVICON` to your own. Do not present
an instance as Gesoft's.
